A modern **AI-inspired Language Learning Web Application** that helps users learn multiple languages through **translation, pronunciation, stories, mini lessons, and interactive learning**.

Designed with a modern UI using **HTML, CSS, and Vanilla JavaScript**, SpeakSpark offers an engaging and beginner-friendly language learning experience.

# ✨ Features

## 🌎 Multi-Language Learning

Supports:

- 🇺🇸 English
- 🇪🇸 Spanish
- 🇫🇷 French
- 🇩🇪 German
- 🇯🇵 Japanese
- 🇮🇳 Hindi
- 🇨🇳 Chinese

---

## 🤖 AI Translator

- Instant word translation
- Multiple language support
- Dictionary-based translation
- Fast search
- Pronunciation support

---

## 🔊 Pronunciation

- Built using the Web Speech API
- Native pronunciation
- Language-specific voice support
- Listen
- Pause
- Resume
- Stop

---

## 📖 Story Learning

Every language includes:

- English Story
- Translated Story
- Audio Narration
- Beautiful Reading Interface
